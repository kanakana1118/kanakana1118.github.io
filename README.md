# 叶奏のホームページ

イラスト・小説・開発をまとめた個人ホームページです。
創作と開発の両方をやっていて、それを組み合わせていることが伝わるサイトを目指しています。

公開URL: https://kanakana1118.github.io/

## 掲載するもの

| セクション | 内容 |
| --- | --- |
| Illust | 厳選した一次創作のイラスト。二次創作の作品画像は載せない。ほかの作品は pixiv / Instagram などへのリンクで案内 |
| Novel | 書いている小説。本が開く演出で、タイトル・あらすじ・読める場所へのリンクを載せる |
| Dev | 作ったホームページなどの概要（スクリーンショット、役割、使用技術） |
| Crossover | 創作と開発が組み合わさったもの |
| About | プロフィール、SNSリンク、参加した同人イベント（会場の様子の写真つき）、公募歴 |

## デザイン

黒基調です（背景は `#0A0A11`）。ページごとに差し色が変わります。

| ページ | 差し色 |
| --- | --- |
| About | 赤 |
| Illust | 橙 |
| Novel | 黄 |
| Dev | 緑 |
| Crossover | 青 |

- **Top:** 動画（タイムラプス）→ 暗転 → メニュー、の順に進みます。メニューは、この5色の水晶玉です。同じ訪問の2回目以降と、OSで「視差効果を減らす」を選んでいる人には、動画を飛ばします。
- **Illust:** 横にめくるスライダー。X・Instagram・pixiv のアイコンから、外部サイトへ移動します。
- **Novel:** 開くと本が立体的に開き、タイトルとあらすじが浮かび上がります。
- **Dev:** グリッド線と発光の、サイバー空間のような見た目。上から順に現れます。

## 構成

静的なHTML/CSSと、小さなJavaScriptだけで作っています。ビルドや依存パッケージはありません。

```
.
├── index.html           トップページ
├── style.css            共通スタイル（黒基調・スマホ対応）
├── script.js            動きの処理（トップの動画→暗転、スライダー、小説の切り替え、上に戻るボタン）
├── noscript.css         JSが使えない場合に、トップのメニューを直接見せる
├── fonts/               Webフォント（Kokoro・Zen Old Mincho。ライセンス全文入り）
├── illust/index.html    イラスト
├── novel/index.html     小説
├── dev/index.html       開発物
├── crossover/index.html 創作×開発
├── about/index.html     プロフィール・SNS・参加イベント・公募歴
├── images/              画像置き場（top / illust / dev）
└── videos/              トップのタイムラプス動画の置き場
```

内容がまだ決まっていない部分は「【仮】」と書いてあります。

## 作品を追加する

各一覧ページには、同じ形のカード（`<article class="card">`）が並んでいます。
既存のカードを1つコピーして、タイトル・説明・画像・リンクを書き換えてください。

画像を追加するときは、撮影情報などのメタデータ（EXIF）を消してから `images/` に置きます。
画像は縮小したものだけを置き（長辺1600px以内、1枚500KB以下が目安）、原寸は置きません。
トップのイラストは、表示が縦長の画面の上半分なので、幅1000〜1200px程度で十分です。

## トップの動画とイラストを差し替える

- 動画: 無音・30秒以内・8MB以下に縮小し、メタデータ（撮影・編集ソフトの情報など）を消して、`videos/timelapse.mp4` を置き換えます。最後まで再生されると、暗転してメニューに切り替わります。
- イラスト: 幅1000〜1200px、500KB以下の WebP にして、`images/top/top.webp` を置き換えます。縦長の絵は、枠の高さに合わせて上寄りに切り抜かれます（`style.css` の `.menu-art img` の `object-position` で調整できます）。

元の画像は、リポジトリの外（`HomePage-assets/originals/`）に置いてあります。
