# 叶奏の備忘録

イラスト・小説・開発をまとめた個人ホームページです。
創作と開発の両方をやっていて、それを組み合わせていることが伝わるサイトを目指しています。

公開URL: https://kanakana1118.github.io/

## 掲載するもの

| セクション | 内容 |
| --- | --- |
| Illust | 厳選した一次創作のイラスト。二次創作の作品画像は載せない。ほかの作品は pixiv / Instagram などへのリンクで案内 |
| Novel | 書いている小説。本が開く演出で、作品名・キャッチコピー・ジャンル・種別・あらすじ・実績・読める場所（小説家になろう・カクヨム）へのリンクを載せる |
| Develop | 作ったホームページなどの概要（スクリーンショット、役割、使用技術）。URL は `/dev/` |
| Crossover | 創作と開発が組み合わさったもの |
| About | プロフィール、SNSリンク、参加した同人イベント（会場の様子の写真つき）、公募歴 |

## デザイン

黒基調です（背景は `#0A0A11`）。ページごとに差し色が変わり、背景の格子も、その色になります（Top のメニュー画面だけ、格子はありません）。
右上のナビは、Top / About / Illust / Novel / Develop / Crossover の順です。

| ページ | 差し色 |
| --- | --- |
| About | 赤 |
| Illust | 橙 |
| Novel | 黄 |
| Develop | 緑 |
| Crossover | 青 |

- **Top:** 動画（タイムラプス）→ 暗転 → メニュー、の順に進みます。
  - 動画は、中央の縦長の画面で流れます。まわりは、灰色の格子です。動画が再生を始めると、最初の約1.2秒は、テレビの映りが乱れるように、画面が横にざざっとずれながら現れます（長さは `script.js` の `GLITCH_MS`、ずれの大きさは `GLITCH_MAX`）。点滅は、動画が終わる0.5秒前から始まります（`script.js` の `BLACKOUT_LEAD_SEC`）。
  - メニューは、ブラウザの横幅いっぱいのイラストです。玉・名前・説明文は、イラストに対して位置が固定され（イラストの下端から30%の高さ）、イラストと一緒にスクロールします。縦に長い絵なので、PC では、スクロールして玉の位置まで下ろします。読みやすいよう、その後ろに、かなり透けた青みがかった黒のグラデーションを敷いています。スマホでは、玉と文字を小さくしています。
  - 同じ訪問の2回目以降と、OSで「視差効果を減らす」を選んでいる人には、動画を飛ばします。
- **Illust:** 目次は、Pick Up（スライダー）と Gallery で、Gallery の下に、作品名の一覧が付きます（押すと、その作品の位置へ移ります）。先頭と末尾がつながった、横にめくるスライダー（ボタン・矢印キー・タップ・スマホのスワイプ。左右に見えている隣の作品をタップすると、その作品が中央に来ます。右から左へなぞると次へ、左から右へなぞると前へ）。X・Instagram・pixiv のアイコンから、外部サイトへ移動します。スライダーの下には、同じ作品を並べた一覧（Gallery）があり、スクロールして見られます（PC は3列、スマホは2列。掲載順に、左から右へ並びます）。作品を足すときは、スライダーの `<article class="slide">` と、一覧の `<figure>` を、1つずつ足します。
- **Novel:** 最初に、本の表紙が立体的に開きます。表紙は、作品ごとではなく、1冊の共通のものです。キャッチコピーは、左右のページにまたがる1つの文字の箱として、本が開いたあと（ページをめくったあとも）、ページの上に浮かび上がります（`.catch-float`。HTMLの `.catch` の文章をそのまま使います）。作品を切り替えると、本は閉じずに、ページがめくれます。左の作品一覧（作品名とジャンルだけ）から作品を押すと、ページがめくれながら、その作品まで移ります。ボタンのほか、本をタップ（PC ではクリック）しても、めくれます。右のページをタップすると次へ、左のページをタップすると前へ戻ります。スマホでは、本を左右になぞる（スワイプ）ことでも、めくれます（右から左へ＝次、左から右へ＝前）。表紙は青みがかった濃い茶色、紙は青みのある薄灰色で、少し下から見上げた角度です。
- **Develop:** 目次は、作品名の一覧です。スクリーンショットと、枠線で囲んだ説明の箱を、互い違いに並べます（スマホでは縦積み）。画面に入ると、大小の四角が上から順に消えて、中身が現れます。
- **About:** 目次は、プロフィール・Links・イベント・公募歴です。左に、トップと同じイラスト（象徴）、右にプロフィール。下に、イベントと公募歴。
- **左の目次（共通）:** 左の一覧（目次）は、About・Illust・Novel・Develop・Crossover の全ページにあります。幅1360px以上の画面では、本文の左に出しっぱなしです。それより狭い画面（スマホなど）では、最初は閉じていて、ページの先頭（見出しの上）にある、3本横線の四角いボタンを押すと、左から出てきます（スクロールしても、画面の上に付いてきます）。中身は、ページごとに違います。
- **Crossover:** 左の一覧は「作品一覧」という名前で、各項目の名前と、何と何を掛け合わせているか（例: Novel × Develop）を並べます。

## 見た目を調整する

すべて `style.css` の中です。

| 変えたいこと | 場所 |
| --- | --- |
| 玉の質感・発光・大きさ | 「水晶玉」の `.orbs` の変数（`--orb`、`--orb-glow` など。コメントつき）と `.orb` |
| 点のハイライトの濃さ（透明度） | `.orbs` の `--orb-hl-alpha`（0〜1。今は 0.85。小さいほど透ける）。位置と大きさは `--orb-hl-x`、`--orb-hl-y`、`--orb-hl-size` |
| 玉の、影のようなグラデの光（ハイライトの外側） | `.orbs` の `--orb-sheen`（濃さ。今は 0.2）、`--orb-sheen-angle`（向き。今は 135deg。315deg にすると、左上から光が来る）、`--orb-sheen-reach`（どこまで届くか。今は 45%） |
| トップの「叶奏の備忘録」の位置・大きさ | `.menu-title` の `--title-y`（イラストの上端から何%か。今は 7%）と `font-size` |
| サブページ左上のロゴ・コピーライト | 各ページの `.site-title`（「叶奏の備忘録」）と `<footer>`（「© 2026 叶奏」。Top は、メニュー画面の下端に重なる） |
| ブラウザのタブに出る名前 | 各ページの `<title>`（Top は「叶奏の備忘録」、ほかは「ページ名 \| 叶奏の備忘録」） |
| 玉・名前・説明文のかたまりの高さ | `.menu-ui` の `--menu-y`（イラストの下端から何%か。今は 30%） |
| 玉と文字の後ろのグラデーション（下） | `.menu-shade` の `--shade`（色）、`--shade-h`（高さ）、`--shade-a`（一番濃いところの濃さ。今は 0.78） |
| 「叶奏の備忘録」の後ろのグラデーション（上） | `.menu-shade--top` の `--shade-top-h`（高さ。文字の下端に合わせる。PC 14.5%、スマホ 20%）。色は下と共通。濃さは、`--shade-a`（今は 0.55）で別に決める |
| スマホでの玉と文字の大きさ | style.css の `@media (max-width: 640px)` の中の `.orbs`、`.orb span`、`.menu-name`、`.menu-lead` |
| スマホでの玉の位置 | 同じ `@media` の中の `.menu-ui` の `--menu-top`（玉の上端が、イラストの上端から何%か。今は 55%。顔のあごは約50%） |
| 名前・説明文・玉の下の文字の大きさ | `.menu-name`、`.menu-lead`、`.orb span` の `font-size`（`clamp()`） |
| 玉の並びの形 | `.orb--about` など、各玉の `left` と `top` |
| 色（玉・差し色・格子） | 先頭の `:root` の `--c-red` など |
| 本の色・質感 | `.book` の変数（`--book-cover`、`--book-paper`、`--tilt`、`--book-depth` など） |
| 本の綴じ目の影の濃さ | `.book` の `--gutter-shade`（0〜1。元は 0.34。0 で影なし） |
| 動画の始まりの乱れ（ざざっとずれる） | `script.js` の `GLITCH_MS`（長さ。今は 1200ms。`style.css` の `.intro` の `--glitch-ms` と合わせる）、`GLITCH_MAX`（横にずれる最大の幅。今は 70px）。帯の細かさは `glitch()` の `baseFrequency`。走査線の濃さは `--glitch-a` |
| 点滅の開始 | `script.js` の `BLACKOUT_LEAD_SEC`（動画が終わる何秒前か） |
| Develop の四角の大きさ・速さ | `script.js` の `initReveal`（`cell` と、`delay` の式） |

## 構成

静的なHTML/CSSと、小さなJavaScriptだけで作っています。ビルドや依存パッケージはありません。

```
.
├── index.html           トップページ
├── style.css            共通スタイル（黒基調・スマホ対応）
├── script.js            動きの処理（トップの動画→暗転、スライダー、本のページめくり、Develop の登場演出、上に戻るボタン）
├── noscript.css         JSが使えない場合の見え方（トップのメニュー、Develop の覆い）
├── fonts/               Webフォント（Kokoro・Zen Old Mincho。ライセンス全文入り）
├── illust/index.html    イラスト
├── novel/index.html     小説
├── dev/index.html       開発物（画面の表記は「Develop」）
├── crossover/index.html 創作×開発
├── about/index.html     プロフィール・SNS・参加イベント・公募歴
├── images/              画像置き場（top / illust / dev）
└── videos/              トップのタイムラプス動画の置き場
```

内容がまだ決まっていない部分は「【仮】」と書いてあります。

## 作品を追加する

各一覧ページには、同じ形のカード（`<article class="card">`）が並んでいます。
既存のカードを1つコピーして、タイトル・説明・画像・リンクを書き換えてください。

画像を追加するときは、撮影情報などのメタデータ（EXIF）を消してから `images/` に置きます。
画像は縮小したものだけを置き（長辺1600px以内、1枚500KB以下が目安）、原寸は置きません。
トップのイラストは、ブラウザの横幅いっぱいに広げて表示します。画面に合わせて、画像を使い分けます（下の「トップの動画とイラストを差し替える」を参照）。幅1920px の画面までは、ほぼぼやけません。Retina の大きな画面（幅1440px の2倍表示など）では、少しだけやわらかく見えます。

## トップの動画とイラストを差し替える

- 動画: 無音・30秒以内・8MB以下に縮小し、メタデータ（撮影・編集ソフトの情報など）を消して、`videos/timelapse.mp4` を置き換えます。終わる0.5秒前から点滅が始まり、暗転してメニューに切り替わります。
- イラスト: 次の3つの WebP を、`images/top/` に置き換えます。付属情報（メタデータ）は消しておきます。縦横比は、3:4 にそろえます。

  | ファイル | 大きさ | 使う場所 |
  | --- | --- | --- |
  | `top-1920.webp` | 1920×2560 | トップ（PC など、大きい画面） |
  | `top-1280.webp` | 1280×1707 | トップ（スマホなど、小さい画面）。About の大きい版 |
  | `top-640.webp` | 640×854 | About |

  ブラウザが、画面の大きさに合わせて、トップのどちらの画像を読み込むかを自動で選びます（`index.html` の `srcset`）。

元の画像は、リポジトリの外（`HomePage-assets/originals/`）に置いてあります。
